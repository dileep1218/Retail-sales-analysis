## 📌 Project Overview

End-to-end retail sales analysis on 5,000+ transactions across 5 stores and 5 product categories (2022–2023). The goal was to uncover high-revenue seasonal patterns, store performance trends, and category-level insights to support inventory planning and sales strategy.

---

## 🔍 Key Findings

| Finding | Business Action |
|---|---|
| **3 high-revenue seasonal windows identified** | Pre-plan inventory and promotions |
| Oct–Dec (Festive Season) → ~2x average monthly revenue | Align marketing budgets to Q4 |
| Jan–Feb (New Year) → ~1.5x average monthly revenue | Run targeted January campaigns |
| Jun–Jul (Mid-year Sale) → ~1.3x average monthly revenue | Stock up before June |
| Electronics drives highest revenue per transaction | Prioritise depth in festive season |
